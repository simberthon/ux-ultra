# Sources

UX Ultra is a synthesis. Every rule traces back to one of the sources below. Research done on 23 October 2026.

The 20-law format (law name, one sentence, four instructions, plus the implementation loop and the conflict tiebreak) comes from the post "The UX Laws in My CLAUDE.md" (designbuilding, 1 September 2026). UX Ultra extends it to 30 laws and adds the SaaS playbook, accessibility, ethics, research, and review layers.

## Books

| Book | Author | What UX Ultra takes from it |
|---|---|---|
| The Design of Everyday Things (rev. 2013) | Don Norman | Signifiers, feedback, mapping, constraints, the two gulfs |
| Don't Make Me Think (3rd ed. 2014) | Steve Krug | Self-evident screens, scanning, the trunk test, goodwill |
| Rocket Surgery Made Easy (2010) | Steve Krug | Small, frequent usability tests |

| Refactoring UI (2018) | Adam Wathan, Steve Schoger | Hierarchy by weight and color, systems, action styling |

| Web Form Design (2008) | Luke Wroblewski | Top labels, inline validation on blur |
| Hooked (2014) | Nir Eyal | Core-action friction, investment, and the Manipulation Matrix as an ethics check |
| Deceptive Patterns (2023) | Harry Brignull | The dark pattern taxonomy to avoid |
| The Mom Test (2013) | Rob Fitzpatrick | Asking about past behavior, not opinions |
