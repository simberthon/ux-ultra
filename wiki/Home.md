# UX Ultra wiki

**The UX brief your AI coding agent never got.**

UX Ultra is a Claude Code skill that makes every screen your agent builds usable by default. It carries 30 laws of UX, the classic heuristics, a SaaS playbook, accessibility and ethics rules, and a scored pre-ship review, all written so a model can reason from them.

## The idea in one paragraph

AI tools build interfaces fast and wrong in the same ways every time: three equal buttons, labels hidden in placeholders, errors that wipe your input, a "No data" screen with no way forward. Not because the model is weak, but because nobody gave it a brief. A style guide does not fix it, because a style guide says what things look like, not why they are there. UX Ultra goes one level up, to the psychology, and adds one line that does most of the work: when rules conflict, prioritize clarity, accessibility, user control, and task completion.
