# Brand

## Name

**UX Ultra.** Two words, both capitalized as written here. In code and commands: `ux-ultra`.

## Tagline

**The UX brief your AI coding agent never got.**

Alternates:
- Usable by default.
- Laws, not a style guide.
- Ship screens people get on the first try.

## One-line description

A Claude Code skill that gives your AI agent the laws and playbooks of good SaaS UX, so every screen it builds is clear, fast, accessible, and honest by default.

## Short pitch (for a post or a slide)

Every AI coding tool can build a settings page in ninety seconds. It will look fine, and it will quietly break the rules every product designer learned the hard way. UX Ultra is the missing brief: 30 laws of UX, a SaaS playbook, accessibility and ethics rules, and a scored review, written so the model reasons from principles instead of copying a spec.

## Voice

- Plain and direct. Short sentences, imperative instructions.
- Every claim has a source. No hype.
- Opinionated where the evidence is strong, honest where it is not ("vendor data, directional").
- No emoji, no exclamation marks.

## Proof points you can use

- 30 laws of UX, each with four instructions.
- 15 books and the 10 most-viewed UX videos on YouTube distilled.
- 100+ cited guidelines and articles (NN/g, WCAG 2.2, Baymard, Vercel, Microsoft HAX, Google PAIR).
- A scored pre-ship review with blockers.
- Works as a Claude Code plugin, a copied skill, or a plain rules file for any AI tool.
